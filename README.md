# Nelly sales enablement

Sales docs for the 90-Day Dating Accelerator.

- `Nelly-Sales-Onboarding.pdf`: who we are, the offer, how leads arrive, the avatar, common objections, house rules.
- `Nelly-Sales-Playbook.pdf`: setter call, closing call, objection scripts.

Built from Mitch's trainings and roleplays, the Shawni setter calls, Nelly's closing calls (Fathom), and the GHL calls tagged `dating` from the last two weeks (Mitch and Jake).

## Editing

Edit `onboarding/onboarding.html` or `playbook/playbook.html`, then rebuild:

```
node scripts/build-pdf.js
```

Brand styles are in `assets/brand.css` (colors from nellysudri.com, Anton + Montserrat).

Raw call transcripts are not committed because they contain lead names and contact details.
